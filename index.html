HOW DRYRUN.AI HOOKS THE PIPELINE

How dryrun.ai integrates KeeperHub directly into Daydreams’ live Open Agentic Commerce marketplace to fulfill hackathon requirements FR-1 through FR-9.

01 // THE TRIGGER

Daydreams Task Acceptance

Requesters post paid tasks on Daydreams. Agents bid, complete the work, and submit deliverables. Rather than triggering irreversible on-chain USDC transfers directly from the agent, dryrun.ai intercepts the payout trigger event (FR-1).

FR-1: TASK EVENT DETECTION
02 // THE COMPOSITION

KeeperHub MCP Server

The payout event is translated into an explicit KeeperHub workflow via KeeperHub’s Model Context Protocol (MCP) server. The workflow specifies token, amount, recipient, nonce, and gas parameters without ambiguous prompt interpretation (FR-2).

FR-2: MCP WORKFLOW TRANSLATION
03 // THE DRY-RUN

Off-Chain Pre-Flight Sim

KeeperHub executes an off-chain dry run of the transaction. A human-readable preview and exact state diff are generated without touching the blockchain. Bayesian confidence gates flag any recipient or value drift (FR-3 & FR-7).

FR-3: DRY-RUN PREVIEW & DRIFT CHECK
04 // ZERO RE-INFERENCE

Deterministic Execution

Once approved by policy or human reviewer, KeeperHub executes exactly the reviewed dry-run workflow. Nothing is re-evaluated or re-inferred by an LLM at execution time, eliminating execution drift (FR-4).

FR-4: DETERMINISTIC DISPATCH
05 // TURNKEY MPC SIGNING

Non-Custodial Security

Keys are never held in memory or plaintext files. KeeperHub orchestrates with Turnkey non-custodial MPC wallets, handling private routing, nonces, and MEV protection while broadcasting to the target network (FR-5).

FR-5: TURNKEY MPC SIGNING
06 // IMMUTABLE AUDIT

End-to-End Traceability

Every step—from the original Daydreams task ID to the dry-run output and on-chain transaction hash—is recorded in KeeperHub’s immutable audit ledger for complete auditability (FR-6).
